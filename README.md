# Python para Análisis Numérico

Guía interactiva para aprender Python desde cero y aplicarlo a métodos numéricos.
Ejecuta el código Python directamente en el navegador con Pyodide.

## 🌐 Web

https://rolongfavian.github.io/python-analisis-numerico/

## 🙌 Créditos

Este proyecto está **inspirado en** [30 Days of Python](https://github.com/Asabeneh/30-Days-Of-Python),
creado por **Asabeneh Yetayeh**. Su estructura de aprendizaje progresivo,
sus ejemplos y su enfoque práctico han sido una gran referencia.

El repositorio original se distribuye bajo **licencia MIT**.

Los contenidos de esta web son una **adaptación y reorganización propia**,
con explicaciones, ejemplos y ejercicios añadidos específicamente para
el contexto del **análisis numérico**.

## 🛠️ Tecnologías

- Pyodide (Python en WebAssembly)
- CodeMirror (editor de código)
- Service Worker (caché offline)
- Google Drive API (modo admin)
